# Línea inicial

Arrancar con 4 o 5 productos, no más. De más fácil a más complejo:

1. **Llaveros y charms para cartera**: con retazos, 10–15 min cada uno. Producto de entrada.
2. **Tarjetero minimalista**: 1–2 piezas, cosido a mano, ideal con iniciales.
3. **Funda para termo / portatermo**: muy argentino, se vende todo el año.
4. **Porta AirTag, porta auriculares, organizador de cables**: poco cuero, precio alto.
5. **Posavasos o portayerba**: para armar un "kit mate" de regalo.

## Herramientas a imprimir en 3D (Studio Kame)

- Plantillas de corte y de marcado de puntadas por producto.
- Sello con el logo para marcar el cuero.
- Moldes para formar cuero húmedo (ej. funda de termo).
- 2–3 texturas exclusivas para la primera colección.

## Tendencias que se aprovechan

- Lujo silencioso: simple, buen cuero, sin logos grandes.
- Personalización: iniciales, grabados, colores.
- Objetos chicos para coleccionar: charms, llaveros, accesorios tech.
- Hecho a mano en series cortas: mostrar el proceso en video.
